# 审计页面使用说明

## 🚀 快速开始

### 1. 访问 API 测试页面（推荐第一步）

访问路径：`http://localhost:你的端口/audit/api-test`

**操作步骤**：
1. 登录系统
2. 在左侧菜单选择：**审计 > API 测试**
3. 点击"测试设备借用接口"按钮
4. 查看返回的数据

**预期结果**：
- ✅ 显示绿色的"成功"标签
- ✅ 可以看到返回的数据条数
- ✅ 展开查看完整的 JSON 数据

**如果失败**：
- 检查是否已登录
- 查看浏览器控制台的错误信息
- 确认后端服务是否正常运行

### 2. 查看审计总览页面

访问路径：`/audit`

**页面包含**：
- 📊 维护统计图表（按设备类型）
- 📊 借用统计图表（按部门）
- 📊 人员使用统计（Top 10）
- 📋 设备借用记录表格
- 📝 借用申请表单

**筛选功能**：
- 按日期范围筛选
- 按设备类型筛选
- 点击"刷新"按钮重新加载数据

### 3. 查看其他审计页面

- **借用审计**：`/audit/borrow` - 查看所有设备借用记录
- **人员审计**：`/audit/personnel` - 查看人员借用统计
- **维护审计**：`/audit/maintenance` - 查看维护统计图表

## 🔍 如何排查问题

### 方法 1: 查看浏览器控制台

1. 按 `F12` 打开开发者工具
2. 切换到 `Console` 标签
3. 刷新页面
4. 查找以下日志：

**成功的日志**（带 📊 图标）：
```
📊 [审计总览] 获取到的设备数据: {total: 100, items: Array(10)}
```

**失败的日志**（带 ❌ 图标）：
```
❌ [审计总览] 数据加载失败: Error: Request failed
```

### 方法 2: 查看网络请求

1. 在开发者工具中切换到 `Network` 标签
2. 刷新页面
3. 找到 `/api/audit/devices` 请求
4. 点击查看详情
5. 查看 `Response` 标签，确认数据格式

**正确的响应格式**：
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "total": 100,
    "page": 1,
    "size": 10,
    "items": [...]
  }
}
```

### 方法 3: 使用 API 测试页面

最简单的方法！直接访问 `/audit/api-test` 页面，一键测试所有接口。

## ❓ 常见问题

### Q: 页面显示"暂无数据"
**原因**：后端返回的数据为空

**解决**：
1. 使用 API 测试页面确认接口是否返回数据
2. 检查数据库中是否有数据
3. 检查筛选条件是否过于严格

### Q: 图表不显示
**原因**：维护统计接口未实现或返回空数据

**解决**：
1. 测试维护统计接口（在 API 测试页面）
2. 确认后端接口 `/api/audit/maintenance/stats` 已实现
3. 查看浏览器控制台是否有错误

### Q: 显示 401 未授权
**原因**：Token 过期或未登录

**解决**：
1. 重新登录
2. 检查用户是否有管理员权限（R_ADMIN）

### Q: 一直显示加载动画
**原因**：API 请求超时或失败

**解决**：
1. 检查后端服务是否运行
2. 查看 Network 标签的请求状态
3. 查看 Console 的错误日志

## 📋 后端接口清单

审计功能需要以下接口：

### 必需接口
✅ **设备借用记录**
- 接口：`GET /api/audit/devices`
- 说明：获取设备借用记录列表（分页）

✅ **维护统计**
- 接口：`GET /api/audit/maintenance/stats`
- 说明：获取按设备类型分组的维护统计

### 可选接口（未实现时会自动计算）
⭕ **借用统计**
- 接口：`GET /api/audit/borrow/stats`
- 说明：如未实现，会基于设备借用数据自动计算

⭕ **人员Top统计**
- 接口：`GET /api/audit/personnel/top`
- 说明：如未实现，会基于设备借用数据自动计算

⭕ **借用申请**
- 接口：`POST /api/audit/borrow-requests`
- 说明：提交借用申请

## 🎯 快速验证步骤

按以下顺序验证：

### ✅ 步骤 1: 测试接口
访问 `/audit/api-test`，点击"测试设备借用接口"

### ✅ 步骤 2: 查看总览
访问 `/audit`，确认：
- [ ] 能看到加载动画
- [ ] 加载完成后显示数据或"暂无数据"
- [ ] 图表能正常显示
- [ ] 表格有数据

### ✅ 步骤 3: 查看控制台
按 F12 打开控制台，确认：
- [ ] 有绿色的 📊 日志
- [ ] 没有红色的 ❌ 错误
- [ ] Network 请求都是 200 状态

### ✅ 步骤 4: 测试筛选
在审计总览页面：
- [ ] 选择日期范围筛选
- [ ] 选择设备类型筛选
- [ ] 点击"重置"按钮
- [ ] 点击"刷新"按钮
